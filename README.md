# Chalo Chalein - Tour & Travel Agency Website

[![Next.js](https://img.shields.io/badge/Next.js-14.0.4-black)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-18-blue)](https://reactjs.org/)
[![License](https://img.shields.io/badge/License-Private-red)](LICENSE)

A modern, responsive travel and tour agency website for **Chalo Chalein** - your premier partner for exploring the beautiful landscapes of Himachal Pradesh. The name "Chalo Chalein" translates to "Let's go" in Hindi, perfectly capturing the spirit of adventure and exploration.

## 🎯 Overview

Chalo Chalein is a comprehensive travel platform offering seamless taxi booking services, curated tour packages, and thrilling adventure activities across Himachal Pradesh. The website provides an intuitive user experience for booking transportation, exploring destinations, and discovering exciting activities like trekking, paragliding, and camping.

## ✨ Features

### Core Services
- **🚕 Taxi Booking Services** - Easy-to-use taxi booking system for Dharamshala and surrounding areas
- **🗺️ Tour Packages** - Curated tour packages for popular destinations
- **🏔️ Adventure Activities** - Booking for trekking, paragliding, and camping experiences
- **📍 Destination Guides** - Comprehensive information about popular Himachal Pradesh destinations

### Website Features
- **📱 Fully Responsive Design** - Optimized for all devices (mobile, tablet, desktop)
- **⚡ Fast Performance** - Built with Next.js 14 for optimal loading speeds
- **🔍 SEO Optimized** - Comprehensive structured data (Schema.org) for better search visibility
- **📝 Contact Forms** - Integrated contact and booking forms with email notifications
- **💬 Real-time Communication** - WhatsApp integration and call buttons for instant customer support
- **⭐ Testimonials** - Customer reviews and testimonials section
- **📸 Image Gallery** - Visual showcase of destinations and activities
- **❓ FAQ Section** - Frequently asked questions to assist visitors

## 🛠️ Tech Stack

### Frontend
- **Next.js 14.0.4** - React framework for production

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm, yarn, pnpm, or bun package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd chalochalein
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application.
